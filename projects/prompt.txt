У меня вот такой формат:
- не нумерованый список
+ нумерованный список

- First
 - First First
 - First Second
- Second

+ First
 + First First
 + First Second
+ Second

если ты делаешь подпункты и хочешь чтобы сохранилась нумерация глобальных пунктов то надо все что между глобальными пунктами отделять пробелом
+ Первый пункт
 - Подпункт
  - Подподпункт
 текст перед вторым под пунктом с пробелом потому что надо сохранить глобальную нумерацию
 - Второй подпункт
+ Второй пункт

= Заголовок первого типа(для пунктов в отчете по типу цели задачи, теоретические сведения, заключение)
== Заголовок второго типа(поменьше)
