# PC3 — консоль R1 + хост «PC-A»

Двойная роль:
1. **Консоль:** rollover-кабель → CONSOLE R1. Вводишь ВСЮ конфигурацию R1 по файлу `R1_настройка.md` (сброс, база, NAT, PAT, Static NAT) — самая большая роль в лабе.
2. **Ethernet:** патч-корд → S1 Fa0/6. Ты — «PC-A» методички, IP **192.168.1.2**. Именно на тебя нацелен Static NAT в Части 4 (209.165.200.229 → 192.168.1.2).

## 1. Сетевая карта (Windows)
- `Win+R` → `ncpa.cpl` → адаптер Ethernet → Свойства → «IP версии 4 (TCP/IPv4)» → Свойства:
  - IP: `192.168.1.2`, маска: `255.255.255.0`, шлюз: `192.168.1.1`, DNS не нужен.
- Проверка в cmd: `ipconfig /all`, затем `ping 192.168.1.1` (шлюз = R1).
- Статический IP нужен с Части 2, при Части 1 можно не спешить.

## 2. Консоль R1
Tera Term → Serial → COMx, 9600 8-N-1. Дальше строго по файлу `R1_настройка.md`:
раздел 0 (сброс) → 1 (база) → 2 (NAT) → 3 (PAT) → 4 (Static NAT). Все команды — оттуда.

## 3. Твои тесты как хоста
- **Часть 2b:** `ping 209.165.200.1` → должен пройти; на R1 появится трансляция 192.168.1.2 → 209.165.200.227 (это ты).
- **Часть 3 (массовый тест):** `ping -t 209.165.200.1` — бесконечный пинг; остановить — **Ctrl+C**.
- **Часть 4:** R2 будет пинговать ТЕБЯ по адресу 209.165.200.229. Входящий ICMP может резать брандмауэр Windows. В cmd **от администратора**:
  ```
  netsh advfirewall firewall add rule name="Allow ICMPv4-In" protocol=icmpv4:8,any dir=in action=allow
  ```
  (или временно отключи брандмауэр в Панели управления).
