# S2 — свич LAN №2

**Подключение:** консольный кабель от **PC2** → порт CONSOLE S2.
**Ethernet-порты S2 (НЕ гасить!):** Fa0/1 → S1 Fa0/1, Fa0/18 → PC4. Остальные — shutdown.

## 0. Сброс свича
```
enable
delete flash:vlan.dat
```
- `Delete filename [vlan.dat]?` → **Enter**
- `Delete flash:vlan.dat? [confirm]` → **Enter**
```
erase startup-config
```
- `Continue? [confirm]` → **Enter**
```
reload
```
- `Save? [yes/no]` → **no**; `Proceed with reload? [confirm]` → **Enter**
- после загрузки: `initial configuration dialog?` → **no**

> Порядок важен: `vlan.dat` и конфиг стираются ДО reload.

Проверка: `show vlan brief`, `show running-config`.

## 1. Базовая настройка

```
configure terminal
hostname S2
no ip domain-lookup
enable secret class
line console 0
 password cisco
 login
line vty 0 15
 password cisco
 login
exit
service password-encryption
banner motd #Authorized Users Only!#
interface vlan 1
 ip address 192.168.1.12 255.255.255.0
 no shutdown
exit
ip default-gateway 192.168.1.1
interface range fa0/2 - 17 , fa0/19 - 24 , gi0/1 - 2
 shutdown
end
copy running-config startup-config
```
- `ip default-gateway` — обязателен, иначе пинги со S2 за пределы подсети не уходят.
- если свич 48-портовый — добавь в range `fa0/25 - 48`.

## 2. Проверка
```
show interfaces status    → connected: Fa0/1, Fa0/18; остальные disabled
show ip interface brief   → Vlan1 192.168.1.12 up
ping 192.168.1.1          → шлюз (R1) отвечает
```

## 3. Тесты по ходу лабы (на этой же консоли, priv EXEC)

**Часть 2d:**
```
ping 209.165.200.1
```
**ДОЛЖЕН ПРОВАЛИТЬСЯ** — это правильный результат лабы! В Части 2 пул из 3 адресов уже занят: PC4 (.226), PC3 (.227), S1 (.228). NAT «один к одному». Фиксируешь провал как ожидаемый результат. Ошибку у себя НЕ искать.

**Часть 3 (массовый тест PAT):**
```
ping 209.165.200.1 repeat 2000
```
Здесь уже должен работать — PAT различает потоки портами, тремя адресами не ограничен. Прервать досрочно — **Ctrl+Shift+6**.
