# Lab 8 — Configure NAT for IPv4 (роутеры 2800 series + свичи 2960)

Лаба разбита по устройствам: **каждый файл = что делать на одном устройстве/ПК**.
Оборудование: R1, R2 (2801/2811), S1, S2 (2960), PC1–PC4.
Интерфейсы роутеров: **F0/0** (внешний, к R2) и **F0/1** (внутренний, в LAN). В методичке они названы G0/0/0 и G0/0/1 — это для 4221, у 2800 они FastEthernet.

## Где выполняется каждый пинг 209.165.200.1 (не путать!)
| Источник | Где вводится команда | Часть 2 (NAT-пул) | Часть 3 (PAT) |
|---|---|---|---|
| PC4 (PC-B) | Windows cmd **на PC4** | ✔ → .226 | ✔ через .230 |
| PC3 (PC-A) | Windows cmd **на PC3** | ✔ → .227 | ✔ через .230 |
| свич S1 | консольная сессия S1 (терминал на PC1), приглашение `S1#` | ✔ → .228 | ✔ |
| свич S2 | консольная сессия S2 (терминал на PC2), приглашение `S2#` | ✘ ожидаемо (пул исчерпан) | ✔ |
| Windows PC1/PC2 | — | пинговать НЕЧЕМ: у них нет Ethernet-кабеля, это только терминалы | — |

Пинг в Windows-окне на PC1/PC2 ≠ пинг со свича. Пинг со свича вводится внутри терминала, где открыта консоль свича (приглашение S1>/S2#).

Как вставлять: блоки команд в файлах устройств можно вставлять в консоль целиком — строки с `!` IOS игнорирует. Разделы «Сброс» НЕ вставлять — там интерактивные вопросы, отвечать руками.
