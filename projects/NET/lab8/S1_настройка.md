# S1 — свич LAN №1

**Подключение:** консольный кабель от **PC1** → порт CONSOLE S1.
**Ethernet-порты S1 (НЕ гасить!):** Fa0/1 → S2 Fa0/1, Fa0/5 → R1 F0/1, Fa0/6 → PC3. Остальные — shutdown.

## 0. Сброс свича
```
enable
delete flash:vlan.dat
```
- `Delete filename [vlan.dat]?` → **Enter**
- `Delete flash:vlan.dat? [confirm]` → **Enter**
```
erase startup-config
```
- `Continue? [confirm]` → **Enter**
```
reload
```
- `Save? [yes/no]` → **no**; `Proceed with reload? [confirm]` → **Enter**
- после загрузки: `initial configuration dialog?` → **no**

> Порядок важен: `vlan.dat` и конфиг стираются ДО reload, иначе переживут перезагрузку.

Проверка: `show vlan brief` (все порты в VLAN 1), `show running-config` (пусто).

## 1. Базовая настройка

```
configure terminal
hostname S1
no ip domain-lookup
enable secret class
line console 0
 password cisco
 login
line vty 0 15
 password cisco
 login
exit
service password-encryption
banner motd #Authorized Users Only!#
interface vlan 1
 ip address 192.168.1.11 255.255.255.0
 no shutdown
exit
ip default-gateway 192.168.1.1
interface range fa0/2 - 4 , fa0/7 - 24 , gi0/1 - 2
 shutdown
end
copy running-config startup-config
```
- `ip default-gateway` — без него S1 НЕ сможет пинговать 209.165.200.1 в Части 2 (пинг уходит за пределы подсети, нужен шлюз).
- у 2960 VTY-линий 16 → `line vty 0 15`.
- если свич 48-портовый — добавь в range `fa0/25 - 48`; если нет Gi0/1-2 — убери их из range.

## 2. Проверка
```
show interfaces status    → connected: Fa0/1, Fa0/5, Fa0/6; остальные disabled
show ip interface brief   → Vlan1 192.168.1.11 up
ping 192.168.1.1          → шлюз (R1) отвечает
```

> **Если Fa0/5 = notconnect:** кабель к роутеру должен идти в **R1 F0/1** (192.168.1.1), а НЕ в R2. У R2 порт F0/1 в этой лабе не используется и не настраивается — порт роутера без конфига по умолчанию выключен (`administratively down`), поэтому линк не поднимется. Перекинь кабель в R1 F0/1 и проверь на R1 `show ip interface brief` (F0/1 up/up).

## 3. Тесты по ходу лабы (на этой же консоли, priv EXEC)

**Часть 2c** (после того как PC4 и PC3 пропинговали):
```
ping 209.165.200.1
```
Должен пройти. На R1 появится трансляция 192.168.1.11 → 209.165.200.228 (PC3 покажет).

**Часть 3 (массовый тест PAT):**
```
ping 209.165.200.1 repeat 2000
```
Пусть идёт, пока PC3 смотрит таблицу на R1. Прервать досрочно — **Ctrl+Shift+6**.
