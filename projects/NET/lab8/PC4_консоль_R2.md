# PC4 — консоль R2 + хост «PC-B»

Двойная роль:
1. **Консоль:** rollover-кабель → CONSOLE R2. Настраиваешь R2 по файлу `R2_настройка.md` (сброс, база, loopback «интернет»).
2. **Ethernet:** патч-корд → S2 Fa0/18. Ты — «PC-B» методички, IP **192.168.1.3**.

## 1. Сетевая карта (Windows)
- `Win+R` → `ncpa.cpl` → адаптер → Свойства → «IP версии 4 (TCP/IPv4)» → Свойства:
  - IP: `192.168.1.3`, маска: `255.255.255.0`, шлюз: `192.168.1.1`, DNS не нужен.
- Проверка в cmd: `ipconfig /all`, затем `ping 192.168.1.1`.

## 2. Консоль R2
Tera Term → Serial → COMx, 9600 8-N-1. По файлу `R2_настройка.md`: раздел 0 (сброс) → 1 (база + Loopback1 209.165.200.1/27) → 2 (проверка). В Части 4 сделаешь тестовый пинг с R2.

## 3. Твои тесты
- **Часть 2a — ПЕРВЫЙ пинг лабы:** `ping 209.165.200.1` → должен пройти; на R1 появится трансляция 192.168.1.3 → 209.165.200.226 (PC3 покажет).
- **Часть 3 (массовый тест):** `ping -t 209.165.200.1` — бесконечный пинг, остановить **Ctrl+C**.
- **Часть 4 (на консоли R2):** `ping 209.165.200.229` — должен проходить (попадает в PC3). Если нет — на PC3 не разрешён ICMP в брандмауэре.
