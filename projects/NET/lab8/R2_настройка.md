# R2 — роутер «интернета»

**Подключение:** консольный кабель от **PC4** → порт CONSOLE R2.
**Порты:** F0/0 → R1 F0/0 (публичная сеть); **Loopback1** = «интернет», на него все пингуют.
NAT на R2 НЕ настраивается — только база + loopback. Позже (Часть 4) с него делается один тестовый пинг.

## 0. Сброс роутера
```
enable
write erase
```
- `Continue? [confirm]` → **Enter**
```
reload
```
- `Save? [yes/no]` → **no**; `Proceed with reload? [confirm]` → **Enter**
- после загрузки: `initial configuration dialog?` → **no**; `terminate autoinstall?` → **Enter** (если спросит)

Проверка: `show startup-config` (пусто), `show ip interface brief`.

## 1. Базовая настройка

```
configure terminal
hostname R2
no ip domain-lookup
enable secret class
line console 0
 password cisco
 login
line vty 0 4
 password cisco
 login
exit
service password-encryption
banner motd #Authorized Users Only!#
interface f0/0
 ip address 209.165.200.225 255.255.255.248
 no shutdown
interface Loopback1
 ip address 209.165.200.1 255.255.255.224
end
copy running-config startup-config
```
Loopback поднимается сам — `no shutdown` не нужен.

## 2. Проверка
```
show ip interface brief   → F0/0 up/up (209.165.200.225), Loopback1 up/up (209.165.200.1)
show ip route             → две connected-сети: 209.165.200.224/29 (F0/0) и 209.165.200.0/27 (Lo1)
```
Когда R1 настроен: `ping 209.165.200.230` — линк до R1 жив.

## 3. Тест Части 4 (когда PC3 настроит Static NAT на R1)

В priv EXEC:
```
ping 209.165.200.229
```
Должно проходить — R2 «стучится из интернета» на публичный адрес PC-A (это PC3). Если молчит — на PC3 не разрешён ICMP в брандмауэре.
После этого PC3 на R1 в `show ip nat translations` увидит запись с портами — лаба пройдена.
