# PC2 — консольная станция S2

Роль: только терминал для настройки S2. **Ethernet PC2 ни к чему не подключается.**
Конфигурация берётся из файла `S2_настройка.md`.

## 1. Подключение и терминал
- Rollover-кабель: RJ-45 → порт **CONSOLE** на S2; второй конец (DB-9) → COM-порт PC2. Нет COM-порта — USB→COM адаптер.
- Tera Term: New connection → **Serial** → COM-порт → OK. Setup → Serial port…: **9600**, 8-N-1, flow control **none**.
- Enter → приглашение `Switch>`.

## 2. Таймлайн работы
1. **Сброс S2** — раздел «0» файла `S2_настройка.md` (vlan.dat → Enter; `Save?` → **no**; setup dialog → **no**).
2. **База** — блок раздела 1. Проверь `show interfaces status` и `ping 192.168.1.1`.
3. **Часть 2d:** `ping 209.165.200.1` со S2 → **ДОЛЖЕН ПРОВАЛИТЬСЯ**. Это не ошибка: в Части 2 пул из 3 адресов уже занят PC4 (.226), PC3 (.227) и S1 (.228), а NAT — «один к одному». Запиши провал как ожидаемый результат (это вопрос лабы).
4. **Часть 3 (массовый тест):** `ping 209.165.200.1 repeat 2000` — теперь должен идти (PAT различает потоки портами). Прервать — **Ctrl+Shift+6**.
