# Руководство по работе с классами и объектами в C++

На примере небольшого C++ класса **MyInt** будет рассмотрено:
- объявление классов в C++: состояние (атрибуты класса), поведение (методы)
- определение поведения класса
- работу с объектами
- перегрузки функций, операторов
- расширение системы типов C++ относительно Си (ссылки)

Класс **MyInt** будет реализовывать обёртку над одним целочисленным значением, хранимым на куче.

## 0. Добавление точки входа для консольного приложения

Необходимо настроить проект - приложение командной строки:

### Visual Studio
- пустой проект C/C++
- точка входа - .cpp файл с функцией _main_

### Unix (g++ / clang++)
- точка входа - .cpp файл с функцией _main_

#### Точка входа приложения командной строки
```
int main(int argc, char* argv[])
{
    // код для тестирования разрабатываемого класса
    return 0;
}
```

## 1. Объявление класса

Класс в C++ следует объявлять в отдельном заголовочном файле (.h). Для объявления класса используется ключевое слово _class_:
```
// file: myint.h

class MyIntPod {
    // пустой класс
};
```

### Атрибуты
Атрибуты - данные класса, определяющие возможные состояния объектов этого класса. Синтаксис объявления атрибутов C++ классов аналогичен синтаксису объявления полей структур в Си:
```
class MyIntPod {
    int* _value; // атрибут для хранения указателя на целочисленное значение на куче
    bool _initialized; // булевый флаг, указывающий на факт наличия значения на куче
}
```

### MyIntPod - структура

Объявленная сущность **MyIntPod** - **не** является классом. Это обычная Си структура, также обозначаемая в C++ терминов POD - **P**lain **O**ld **D**ata.

С точки зрения ОО парадигмы **MyIntPod** также не является классом, так как не содержит поведения.

### Объявление настоящего класса 

Объявляемая с помощью _class_ сущность будет классом, когда в объявление будет задано её поведение с помощью:
- методов
- конструкторов
- деструктора

#### Методы
Методы - функции класса, определяющие различное поведение объекта. Методы объявляются внутри тела класса (блок {} после имени класса) синтаксисом схожим с синтаксисом объявления функций в Си:
```
#include <iostream> // модуль I/O из стандартной библиотеки C++

сlass MyInt {
// ...
public:
    void print_identity() { // метод класса MyInt
        std::cout << this << "\n"; // this - ключевое слово, хранящее указатель на объект, с которым ведётся работа (можно считать, что тип this - MyInt * const - константный указатель на объект)
    }
}
```

_NOTE_: Ключевое слово _public_ перед объявлением методов - модификатор доступа к методам (реализация принципа инкапсуляции объектной модели). Указание модификатора доступа _public_ позволяет стороннему коду вызвать методы класса на созданных объектах.

#### Конструкторы
Конструкторы - специальный тип методов, вызываемых при создании объекта класса для выполнения его инициализации. Конструкторы объявляются как функции с названием, совпадающим с названием класса и **без** указания типа возврата:
```
// ...

class MyInt {


public:
    MyInt() {
        cout << "initializing via default .ctor\n";
        _initialized = false;
        _value = nullptr; // nullptr - непроинициализированный указатель на объект
    }

    MyInt(int initial_value) {
        cout << "initializing via .ctor(int)\n";
        _value = new int;
        *_value = initial_value;
    }
}
```

#### Деструктор
Деструктор - специальный тип метода, вызываемый при завершении работы с объектом (перед его высвобождением памяти, используемой объектом). Деструктор предназначен для освобождения внутренних ресурсов, созданных в ходе жизни объекта. Например:
- закрытие файловых дескриптор
- закрытие сокетов
- высвобождение выделенной на куче памяти

Синтаксис объявления деструктора:
class MyInt {
public:
    ~MyInt {
        // высвобождение ресурсов
        if (_initialized) 
            *_value = 0;
            delete _value;
        }
    }
}

_NOTE_: Класс в С++ также может быть объявлен с помощью ключевого слова _struct_. Выбор ключевого слова влияет на параметры инкапсуляции атрибутов класса.

## 2. Определение методов в .cpp файлах

В примерах кода выше тела методов были определены непосредственно в теле (объявление) класса. Данный способ определения служит предписанием компилятору на inline компиляцию метода. Поэтому, данный способ определения следует применять **только для небольших** методов (например - методов доступа к данных класса).

Объемные по коду методу следует только объявлять в блоке класса:
```
// file: myint.h

class MyInt {
public:
    void print_identity(); // объявление метода
}
```

Определение тело метода необходимо помещать в одноимённый файл с расширением .cpp:
```
// file: myint.cpp
#include "myint.h"

void MyInt::print_identity() {
    cout << this << "\n";
}
```

_NOTE_: Префикс _MyInt::_ указывает на принадлежность определяемого метода класса **MyInt**. Данный префикс необходим, т.к. несколько различных классов могут иметь одноимённые методы.

## 3. Работа с объектами

Текущего объявления класса **MyInt** с двумя атрибутами достаточно для создания экземпляров класса - объектов.

Для использования класса в программе на C++ необходимо:
- подключить заголовочный файл с объявлением класса к .cpp-файлу, в котором он будет использоваться
- создать экземпляр класса

### Создание объектов класса

Создание объектов класса с точки зрения их расположения в памяти процесса полностью аналогично ситуации со структурами в Си. Объекты могут располагаться:
- на стеке
```
void foo1() {
    MyInt onStack;
}
```
- на куче: объект создаётся с помощью ключевого слова _new_
```
void foo2() {
    MyInt* onHeap = nullptr; // непроинициализированный указатель на объект класса MyInt
    onHeap = new MyInt();
}
```
- в секции глобальных данных, в случае объявления экземпляров класса в глобальной области видимости:
```
class MyInt {
    // ...
} GlobalMyInt(123);
```

_NOTE_: ключевое слово new в C++ отвечает за создание экземпляров класса в случае указания после него имени класса с набором параметров для конструктора. Например при вызове _MyInt* ptr = new MyInt(15);_ будет выполнено:
- выделение памяти под объект на куче
- инициализация созданного объекта с помощью конструктора MyInt(int)

### Вызов методов класса
Вызов методов класса происходит путём обращения к объявленным методам класса с помощью синтаксиса, аналогичного обращению к полям Си структур, имеющим тип указателя на функцию:
```
// main.cpp

int main(int argc, char* argv[]) {
    MyInt myint1(1);
    myint.print_identity(); // вызов метода на объекте, хранимом на стеке

    MyInt* myintPtr = &myint1;
    myintPtr->print_identity(); // вызов метода через указатель на объект
}
```

### Освобождение ресурсов объектов
Освобождение ресурсов из-под объектов выполняется с помощью методов-деструкторов.

В случае локального объявления объектов на стеке деструктор будет вызван автоматически при выходи из зоны видимости локальной переменной, в которой хранится объект:
```
int main(int argc, char* argv[]) {
    MyInt onStack(123);
    // ...


    // неявный вызов деструктора ~onStack();
    return 0;
    
}
```

В случае выделения объектов на куче с помощью ключевого слова _new_ необходимо выполнить явное освобождение памяти из-под объекта на куче с помощью ключевого слова _delete_:
```
int main(int argc, char* argv[]) {
    MyInt* onHeap = new MyInt(321);
    // ...

    delete onHeap; // в случае отсутствия строчки произойдёт утечка памяти, т.к. будет потерян последний указатель на выделенный на куче объект
    return 0;
}
```

## 4. Перегрузки методов, операторов класса

### Перегрузка методов
На примере конструкторов класса MyInt уже просматривалась возможность определения поведения класса (методов), имеющих одинаковое название. 

Данная возможность C++ называется перегрузкой методов. Каждое определение перегружаемого метода должно иметь уникальный набор параметров (необходимо, для того, чтобы компилятор мог однозначно определить необходимую для вызова метод). Например:
```
// file: myint.h

clas MyInt {
    void add(int a1); // первая-
    void add(int a1, a2); // вторая-
    void add(int a1, int a2, int a3); // третья- перегрузки метода add
}

// file: myint.c
void MyInt::add(int a1) {
    _value += a1;
}
void MyInt::add(int a1, int a2) {
    _value += (a1 + a2);
}
// ...
```

Реализации различных перегрузок методов должны иметь **одинаковую семантику** (тип поведения) и различаться только форматом входных данных. Класс с различной семантикой для разных перегрузок одного метода - пример плохого интерфейса для пользователей класса.

_NOTE_: в скомпилированной программе определения разных перегрузок метода с одним названиям превратятся в **уникальные** функции на машинном языке. Если перегрузки будут обозначены в качестве экспортируемы символов собираемого модуля, им будут присвоены уникальные имена с помощью механизма - name mangling.

### Пергрузка операторов

Помимо перегрузки именованных методов C++ предоставляет возможность переопределения поведения базовых операций языка для объектов заданного класса с помощью механизма **перегрузки операторов**. Например, возможно перегрузить операции сложения (+), присваивания (=), сравнение (==), индексации ([]) и так далее.

Для перегрузки операторов используется ключевое слово _operator_ за которым следует символьное обозначение оператора в синтаксисе C++:
```
// file: myint.h

class MyInt {
    int operator+(MyInt& rightSide);
    int operator+=(MyInt& rightSide);
}

// file: myint.cpp
int MyInt::operator+(MyInt& rightSide) {
    return *_value + *rightSide._value; // NOTE: возможно неопределённое поведение
}

int MyInt::operator+=(MyInt& rightSide) {
    *_value += rightSide._value;
    return *_value;
}

// file: main.cpp
int main(int argc, char* argv[]) {
    MyInt i1(4), i2(6);
    int result = i1 + i2;

    return 0;
}
```

## 5. С++ ссылки (references)

В примере с перегрузкой оператора _MyInt::operator+_ в качестве типа параметра используется значение MyInt **&**.

Данный синтаксис используется для определения ссылочного типа языка C++. Механизм ссылок в C++ позволяет работать с **одним экземпляром** объекта под разными именами. Один из основных случаев применение ссылок - их использование в сигнатурах методов (для типов параметров и типов возврата). Передача параметра по ссылочному типу позволяет передавать объект напрямую на стек вызываемой функции без выполнения копирования и без явного преобразования к указателю.

Сигнатуру определенного выше оператора _MyInt::operator+=_ можно улучшить за счёт использования в качестве типа возврата ссылочного типа:
```
// file: myint.h

class MyInt {
    MyInt& operator+=(const MyInt& rightSide);
}

// file: myint.cpp
MyInt& MyInt::operator+=(MyInt& rightSide) {
    *_value += rightSide._value;
    return *this;
}

// file: main.cpp
int main(int argc, char* argv[]) {
    MyInt i1(4), i2(6), i3(7);
    auto result = i1 + i2 + i3;
    // i3 == 7
    // i2 == 13
    // i1 == 17
    // result (автоопределённый тип - MyInt&) == 17
    // &result == &i1 - один и тот же объект

    return 0;
}
```

_NOTE_: к C++ ссылкам применим модификатор _const_ который указывает, что объект по ссылке запрещено изменять. const ссылки следует использовать для передачи read-only параметров в методы (например, все параметры хорошо спроектированных конструкторов, т.к. семантика конструкторов не подразумевает изменения входных параметров).

### const методы

Также в C++ представлен механизм применения ключевого слова _const_ к методам класса:
```
// file: myint.h
// ...

class MyInt {
    // ...
public:
    void print_identity() const { // объявление (и инлайн определение) метода в качестве константного метода класса
        cout << this << "\n";
    }
}
```

Для константных методов запрещено изменение атрибутов объекта, для которого они вызваны. Другими словами, в случае _const_ методов ключевое слово **this** будет иметь тип _const MyInt * const_ - константный указатель, на константный экземпляр класса.

Модификатор _const_ необходимо указывать для методов, семантика которых не подразумевает изменения состояния объекта. Например, для всевозможных методов извлечения данных из объекта (getter-ов).
