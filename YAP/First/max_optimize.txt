Вот команда для максимально сжатой компиляции:

```bash
gcc -Os -s -ffunction-sections -fdata-sections -Wl,--gc-sections -fno-unwind-tables -fno-asynchronous-unwind-tables -fmerge-all-constants -fno-ident -flto main.c qr_encoder.c -o main -lqrencode -Wl,--strip-all
```

**Пояснение флагов:**

- `-Os` - оптимизация по размеру кода
- `-s` - удаление символов и отладочной информации
- `-ffunction-sections -fdata-sections -Wl,--gc-sections` - удаление неиспользуемых функций и данных
- `-fno-unwind-tables -fno-asynchronous-unwind-tables` - отключение таблиц исключений
- `-fmerge-all-constants` - объединение констант
- `-fno-ident` - отключение идентификатора компилятора
- `-flto` - межмодульная оптимизация
- `-Wl,--strip-all` - полная очистка бинарника

**Дополнительные опции для еще большей минимизации:**

```bash
gcc -Os -s -ffunction-sections -fdata-sections -Wl,--gc-sections -fno-unwind-tables -fno-asynchronous-unwind-tables -fmerge-all-constants -fno-ident -flto -fno-stack-protector -fno-plt -Wl,-z,norelro main.c qr_encoder.c -o main -lqrencode -Wl,--strip-all -Wl,-z,noseparate-code
```

**Для статической линковки (если возможно):**
```bash
gcc -Os -s -static -ffunction-sections -fdata-sections -Wl,--gc-sections -fno-unwind-tables -fno-asynchronous-unwind-tables -fmerge-all-constants -fno-ident -flto main.c qr_encoder.c -o main -lqrencode -Wl,--strip-all
```

**Проверить размер можно командой:**
```bash
strip --strip-all main && ls -la main
```

Эти флаги дадут максимально компактный исполняемый файл за счет агрессивного удаления всего лишнего.
